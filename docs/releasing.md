# Releasing Redrob CAD

The canonical recipe is craftrules' [`release/playbook.md`](https://github.com/storytold/craftrules/blob/main/release/playbook.md); this file covers only what's Redrob CAD-specific.

- **Version:** `[workspace.package] version` in the root `Cargo.toml` is the single source. `cargo xtask version` prints it; `cargo xtask version set X.Y.Z[-pre]` changes it. The app shows it in About, `redrob-cad --version` and `redrob-cad-cli --version`; release builds also embed the commit (`CADCRAFT_BUILD_SHA`).
- **Cut a release:** cut `release/X.Y.Z` from `develop`, run `cargo xtask version set X.Y.Z` there, open a pull request to `main` and merge it with a merge commit. Tag the merge commit `vX.Y.Z` on `main`, push only the tag, then open the back-merge pull request `main` -> `develop`. The tag runs `.github/workflows/release.yml`, which fails if the tag is not the Cargo.toml version, and creates or updates the draft GitHub Release `Redrob CAD vX.Y.Z`. Publish the draft after checking its assets. A `workflow_dispatch` run (optionally with `version: X.Y.Z-rc.N`) is a dry run: every job builds and nothing is drafted.
- **Artifacts:** macOS universal `.dmg` (Developer ID signed, notarized, stapled) and CLI `.zip`; Windows x64, x86 and arm64 `.msi` + portable `.zip` (Azure Trusted Signing); Linux x86_64 and aarch64 `.AppImage` (+ `.AppImage.zsync` for AppImageUpdate delta updates), `.flatpak` bundle (repackages the tarball, `packaging/linux/flatpak-bundle.sh`), `.deb`, `.rpm`, `.tar.gz` (+ the from-source Flathub manifest in `packaging/linux/flatpak/`); FreeBSD x86_64 `.tar.gz` (built in a FreeBSD VM); web `.zip` (wasm + `index.html`, see `packaging/web/README.md`); `SHA256SUMS.txt`.
- **Secrets:** redrob-labs organization secrets. macOS: `APPLE_CODESIGN_CERT_P12_BASE64`, `APPLE_CODESIGN_CERT_PASSWORD` (Developer ID certificate) and `APPLE_NOTARY_API_KEY_P8_BASE64`, `APPLE_NOTARY_API_KEY_ID`, `APPLE_NOTARY_API_ISSUER_ID` (notarization). Windows (Azure Trusted Signing) has no credential for this repository yet, so Windows builds are unsigned. All are optional: a missing one produces unsigned artifacts with a warning.
- **File types:** `.dxf` and `.dwg` (macOS document types, Windows "Open with", Linux MIME types).
- **Local packaging test:** `packaging/macos/package.sh` (ad-hoc signed DMG), `packaging/linux/package.sh`, `packaging/web/package.sh`.
